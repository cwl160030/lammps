   things e.g. REACTOR/KIM FFs and writing the QM atom types to a file is 
   relatively easy. 
  
   Don't need to label every atom, just the atom types! 
   Treats each value as a string. For now use atom numbers. 

   Example for QM Water: 

   8    1
------------------------------------------------------------------------- */
